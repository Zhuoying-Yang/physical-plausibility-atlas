How to interpret a score

The detectors do not all point in the same direction.

Contact · 0–100
Higher ↑ stronger contact-support evidence
A higher score is more favorable for the contact criterion, not a guarantee of causality.
Penetration · 0–1
Higher ↑ more violation evidence
A high verified boundary-crossing score indicates a suspected physical error.
Consistency · 0–1
Higher ↑ more anomaly evidence
A high duplication/birth/death score means less plausible object persistence.

The same video can fail in different ways

Example: Cosmos2.5_0006 is a meaningful cross-metric case.

Human: No Contact · Score: 89.459

Penetration · positive

Human: Penetration · Type A: 0.45

A separate boundary-crossing test finds evidence of penetration. This score measures a different physical failure and should not be averaged with Contact.

Metric 01 / Contact-supported response

Did the object move with plausible contact?

The method does not recover exact 3D contact. It measures whether the video contains a visually plausible robot–object contact event that is followed soon by meaningful object motion.

Find a plausible touch, then ask whether the object responds.
A video receives the highest eligible contact score among candidate events with motion in the next 36 frames.
Frozen method · FuturePair36
Intended behavior Touch → movement
Robot is visibly near or touching the object, and the object later shows tracked motion.
Possible failure Movement without prior touch
Object starts moving before plausible contact. FuturePair36 can miss this ordering error if there is a later valid touch.

Metric 02 / Through solid material

Did something pass through a solid boundary?

The key distinction is a physically impossible solid-wall crossing versus a legitimate opening, going around the edge, or a confusing occlusion.

Passing through the opening is allowed. Passing through the solid wall is not.
The system must identify which object interacts with which solid boundary, then verify the image sequence—not just detect overlap.
Violation-oriented score

Metric 03 / Object identity & persistence

Are the same objects still there?

One video should contain a physically coherent set of objects: no unexplained duplicates, arrivals or disappearances. The current system covers these with separate stages of maturity—not a solved global 3D tracker.

An object should not clone itself, pop into existence, or vanish without explanation.
The main shift: from “two objects look alike in one frame” toward “which instances persist across time?”
Higher = more anomaly evidence

Read carefully / Scope and interpretation

What these numbers do — and do not — mean.

The website is designed to separate verified results from diagnostics, avoid false implications from unscored cases, and make different method stages inspectable.

Score orientation

Contact higher = stronger plausible contact-support evidence. Penetration and consistency higher = stronger anomaly evidence. AUROC/AP higher = better ranking quality in that specific annotated evaluation cohort.

No single calibrated physics score

The methods have different score directions, GT criteria, evaluation sets and coverage. We do not sum, average or rank a video by an invented universal “physics score.”

Unscored vs a real zero

A final score of 0 can be a legitimate method output (e.g., Agent 0 abstains). A failed preprocessing run, missing execution, manual pilot, or unresolved GT is not automatically zero.

Result maturity

Contact FuturePair36 is frozen (46-case evaluation). Penetration A is a 13-case end-to-end test, C is a 6-case development pilot, B unsolved and backward diagnostic. Consistency duplication is most mature, birth/death broader but less certain.
